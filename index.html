Abstract

In three-dimensional coherent diffraction imaging, different objects can produce nearly identical diffraction patterns when only a few orientations are measured. We ask how the choice of object representation affects the Fourier phase variations that can remain hidden in these measurements. Our method, NerEID, represents the object as a set of anisotropic Gaussians. A learned shape prior supplies the initial geometry, which is then refined against the diffraction intensities from all views. In perturbation tests, the Gaussian model reproduced a smaller fraction of imposed phase variations than a fixed voxel model. Across 20 simulated objects reconstructed from three diffraction views each, NerEID improved rendered-view PSNR by 5.70 dB over joint DDRM-PR. Five measured diffraction patterns from planar targets provide a separate experimental test in two dimensions. These results suggest that the object representation offers a practical way to restrict phase ambiguity in sparse-view CDI.
